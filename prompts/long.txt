# 장기 가치 투자 분석 프롬프트 (Long-Term Value Investing Analysis)

## 투자 목표
자산의 50%를 장기(5년+) 우량주·배당성장주 포트폴리오에 배분하여 연 10% 수익을 안정적으로 달성한다.

## 사용 가능한 MCP 도구
- **WebSearch** (내장) — Google 검색으로 최신 뉴스·정책·지정학 이슈 수집
- **discord-reader**: `get_latest_holding` — #holdings 채널 보유 종목 읽기
- **discord-notifier**: `send_discord_message`, `send_stock_alert` — 분석 결과 전송
- **financial-datasets**: `get_income_statement`, `get_balance_sheet`, `get_cash_flow`, `get_company_news`
- **value-investing-tools**: `calc_dcf`, `calc_wacc`, `peer_benchmark`, `value_summary`
- **yfinance**: `get_realtime_price`, `get_stock_info`, `get_multi_quote`
- **macd-analyzer**: `get_macd`, `get_macd_multi`
- **alphavantage**: `get_rsi`, `get_ohlcv`, `get_market_status`
- **free-screener**: `screen_stocks`

## 실행 지침

### STEP 0 — 거시 환경 파악 및 보유 종목 불러오기

**0-A. 거시 경제·뉴스 컨텍스트 수집**
아래 순서대로 수집하여 이후 모든 종목 분석의 배경 맥락으로 활용하라.

1. **Google 검색 (WebSearch)** — 아래 3개 쿼리를 순서대로 검색하라 (**최근 3일 이내** 뉴스만 참고하라):
   - `"stock market economic news last 3 days"` — 미국 시장·경제 동향
   - `"Fed interest rate inflation CPI jobs report"` — 통화정책·거시 지표
   - `"global geopolitical risk trade tariff sanctions"` — 지정학·정치 리스크
   각 검색 결과에서 **발행일이 3일 이내**인 기사의 핵심 헤드라인 2~3개씩 추출하라.
   3일을 초과한 오래된 뉴스는 무시하라.

2. **시장 지표 스냅샷** — yfinance `get_multi_quote` 호출 (tickers: ["SPY", "QQQ", "TLT", "GLD", "VXX"]):
   - SPY/QQQ: 미국 주식시장 전반 방향성
   - TLT: 장기 국채 (상승 = 금리 하락 기대 / 위험 회피)
   - GLD: 금 (상승 = 지정학 리스크 / 달러 약세)
   - VXX: 변동성 (급등 +5% 이상 = 공포 구간)

3. **원자재** — alphavantage `get_commodity_price` 호출:
   - WTI (에너지 비용·인플레이션 압력 지표)
   - GOLD (안전자산 수요·달러 강도 지표)

4. **종목별 뉴스 보완** — financial-datasets `get_company_news` 호출 (ticker="SPY", limit=5):
   - Google 검색에서 파악하지 못한 최신 시장 뉴스를 보완하라.

수집 결과를 아래 형식으로 정리하여 분석 시작 전 Discord에 `send_discord_message`로 전송하라:
```
🌐 거시 환경 스냅샷
  SPY: +X.X% | QQQ: +X.X% | TLT: +X.X% | GLD: +X.X% | VXX: +X.X%
  WTI: $XX.X | GOLD: $X,XXX
  시장 심리: 🟢/🟡/🔴 [한 줄 요약]
  주요 이슈: [Google 검색 기반 핵심 헤드라인 2~3개]
```

> 거시 심리가 🔴 위험 회피일 경우: DCF 보수 시나리오에 더 높은 가중치를 두고,
> 안전 마진 기준을 기본 20%에서 25%로 상향 적용하라.

**0-B. 보유 종목 불러오기 및 종목별 뉴스 수집**
discord-reader MCP의 `get_latest_holding` 툴을 호출하여 #holdings 채널의 가장 최근 메시지를 읽어라.
메시지에서 종목명, 수량, 통화(KRW/USD)를 파싱하라.
분석 대상 종목(티커)이 명시된 경우 해당 종목만 분석하고, 없으면 보유 전체를 분석하라.

보유 종목 목록이 확정되면 각 종목에 대해 아래 2가지를 수집하라 (**최근 3일 이내** 뉴스만):
1. **WebSearch** — `"[종목명] stock news last 3 days"` 쿼리로 검색하여 주요 헤드라인 1~2개 추출
2. **financial-datasets `get_company_news`** — 해당 티커로 호출 (limit=3), 날짜가 3일 이내인 것만 사용

수집한 종목별 뉴스는 이후 STEP 분석에서 리스크·촉매 판단의 근거로 활용하라.
부정적 뉴스(소송·규제·실적 쇼크·CEO 교체 등)가 있으면 해당 종목 분석 카드에 "⚠ 최근 리스크 이슈" 로 명시하라.

### STEP 1 — 재무 건전성 점검 (5개년)

**1-A. 기초 스크리닝 (진입 조건)**
yfinance MCP의 `get_stock_info`를 먼저 호출하여 아래 우량주 기준을 충족하는지 확인하라.
기준 미달 종목은 "⛔ 우량주 기준 미달"로 표시하되 분석은 계속 진행한다.

| 지표 | 기준 | 비고 |
|------|------|------|
| 시가총액 (marketCap) | $100억 이상 | 기관 투자자 유입 및 시장 내성 |
| 배당 성향 (payoutRatio) | 60% 이하 | 재투자 여력 및 배당 지속성 |

**1-B. 재무제표 분석**
financial-datasets MCP를 사용하여:
1. `get_income_statement` (annual, 5년) → 매출 성장률(CAGR), 영업이익률, 순이익 추세
2. `get_balance_sheet` (annual, 5년) → 부채비율(D/E), 유동비율, 자기자본 추세
3. `get_cash_flow` (annual, 5년) → 영업CF, FCF 추세

5개년 **추세** 비교 필수: 최근 1년 수치 외에 5년 평균과 비교하여 하락 추세 여부를 판단하라.
전년 대비 ±50% 이상 이상치는 "⚠ 데이터 이상" 으로 명시하라.

**1-C. 재무 헬스 플래그**
아래 기준으로 종합 등급을 부여하라:
- 🟢 양호: ROE ≥ 15%, D/E ≤ 1.0, 매출 CAGR ≥ 5%
- 🟡 주의: ROE 10~15% 또는 D/E 1.0~2.0
- 🔴 위험: ROE < 10% 또는 D/E > 2.0 또는 순손실 발생

ROE는 순이익 ÷ 자기자본으로 직접 계산하라 (5년 평균 및 최근치 모두 표시).

**1-D. 배당 이력 및 등급**
`get_stock_info` 에서 `dividendYield`, `fiveYearAvgDividendYield`, `exDividendDate` 를 확인하라.
배당 지속 연수를 추정하여 아래 등급을 부여하라:
- 👑 Dividend King: 50년 이상 연속 배당 증액
- 🏅 Dividend Aristocrat: 25~49년 연속 증액
- 🎖 Dividend Achiever: 10~24년 연속 증액
- ⚪ 일반 배당주: 10년 미만 또는 이력 불명
- ➖ 무배당: 배당 없음

### STEP 2 — 내재가치 산출 (DCF / WACC)
value-investing-tools MCP를 사용하여:
1. `calc_wacc` → 현재 무위험수익률(^TNX 자동 조회) 기반 WACC 계산
2. `calc_dcf` → 아래 시나리오 3가지로 DCF 내재가치 산출:
   - **보수**: FCF 성장률 4%, 영구성장률 = 무위험수익률(^TNX), 예측기간 10년
   - **기본**: FCF 성장률 8%, 영구성장률 3%, 예측기간 10년
   - **낙관**: FCF 성장률 12%, 영구성장률 3.5%, 예측기간 10년

   > 영구성장률(Terminal Growth Rate)은 보수 시나리오에서 ^TNX(무위험수익률)에 고정하여
   > 비현실적 낙관론을 배제한다. 기본/낙관 시나리오도 ^TNX + 0.5~1.0%p 이하로 제한하라.

3. 현재 주가와 각 시나리오 내재가치를 비교하여 안전 마진(Margin of Safety)을 계산하라:
   - 안전 마진 = (내재가치 - 현재가) / 내재가치 × 100
   - **매수 적정**: 기본 시나리오 안전 마진 ≥ 20%
   - **관망**: 0% ≤ 안전 마진 < 20%
   - **고평가**: 안전 마진 < 0%

4. `peer_benchmark` → 동종업계 2~4개 종목과 PER, PBR, EV/EBITDA 비교

### STEP 3 — 기술적 신호 확인
- macd-analyzer MCP의 `get_macd`를 호출하여:
  - MACD 히스토그램 방향 (골든크로스 / 데드크로스 / 상승추세 / 하락추세)
- alphavantage MCP의 `get_rsi`를 호출하여:
  - RSI 과매수(>70) / 중립(30~70) / 과매도(<30) 판단
- 신호 요약: "기술적 매수 신호", "중립", "기술적 매도 신호" 중 하나로 판단

### STEP 4 — 최신 뉴스 및 시장 심리
financial-datasets MCP의 `get_company_news`로 해당 종목 최신 뉴스 5건을 조회하라.
각 뉴스의 sentiment를 파악하여 시장 심리를 "긍정적 / 중립 / 부정적"으로 요약하라.

### STEP 5 — 종합 판단 및 Discord 전송
아래 형식으로 **종목별 투자 의견 카드**를 작성한 뒤,
discord-notifier MCP의 `send_stock_alert`로 Discord에 전송하라
(색상: 매수=녹색 0x00b050, 관망=노란색 0xffc000, 고평가=빨간색 0xe74c3c).

```
──────────────────────────────────
📊 [종목명] ([티커]) — 장기 투자 분석
──────────────────────────────────
현재가:      $XXX.XX
내재가치:    $XXX (보수) / $XXX (기본) / $XXX (낙관)
안전 마진:   XX% (기본 시나리오)
투자 의견:   ★ 매수 적정 / 관망 / 고평가

📈 재무 건전성
  시가총액:   $XXX (우량주 기준 충족 여부)
  ROE:        XX% (5년 평균 XX%)  [🟢/🟡/🔴]
  D/E:        X.X  [🟢/🟡/🔴]
  매출 CAGR:  XX%
  배당 등급:  👑/🏅/🎖/⚪/➖ [Dividend King/Aristocrat/Achiever/일반/무배당]
  배당 성향:  XX% [지속가능 ✓ / 주의 ⚠]

💰 밸류에이션 (동종업체 비교)
  PER:   XX배 (업종 평균 XX배)
  PBR:   XX배 (업종 평균 XX배)

📉 기술적 신호
  MACD:  [골든크로스/데드크로스/상승/하락 추세]
  RSI:   XX ([과매수/중립/과매도])
  신호:  [기술적 매수/중립/매도]

📰 뉴스 심리:  [긍정/중립/부정]

💡 매수 적정가:  $XXX (기본 시나리오 20% 안전 마진 기준)
──────────────────────────────────
```

포트폴리오 전체 분석이 끝난 후, `send_discord_message`로 **포트폴리오 요약 메시지**를 별도 전송하라:
- 분석 종목 수, 매수 적정 / 관망 / 고평가 분포
- 가장 높은 안전 마진 종목 (TOP 1)
- 우량주 기준 미달 종목 목록

## 주의 사항
- **재무제표 폴백 규칙**: financial-datasets의 `get_income_statement` / `get_balance_sheet` / `get_cash_flow`
  호출 시 오류가 발생하면, 즉시 yfinance MCP의 `get_financials`로 대체하라.
  yfinance `get_financials`는 API 키 불필요, 미국·한국 주식 모두 지원, 최근 4개년 데이터 제공.
  대체 시 분석 카드에 "📦 재무데이터: yfinance (financial-datasets 오류)" 를 표시하라.
- KRW 종목(예: 138040.KS, 005930.KS)은 financial-datasets에서 지원되지 않으므로
  처음부터 yfinance `get_financials`를 사용하고 "yfinance 데이터" 로 표시하라.
- 금(GC=F) 보유분은 DCF 분석 대상에서 제외하고, 현재 시세(USD/oz)와 보유량만 표시하라.
- ADR 종목(예: KB — KB금융 NYSE ADR)은 원주 종목(티커 .KS)과 중복 분석하지 말고 하나만 분석하라.
- 데이터 취득 실패 시 해당 항목을 "N/A"로 표시하고 분석을 계속 진행하라.
- 각 종목 분석 시작 시 `send_discord_message`로 "[종목] 분석 중..." 진행 상황을 전송하라.
