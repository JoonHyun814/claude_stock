# 단기 모멘텀 매매 분석 프롬프트 (Short-Term Momentum Trading)

## 투자 목표
월 3% 수익 목표. 기술적 지표 조합으로 정밀한 진입 타이밍을 포착하고,
R:R 비율과 포지션 사이징으로 손실을 구조적으로 제한한다.

## 사용 가능한 MCP 도구
- **WebSearch** (내장) — Google 검색으로 최신 뉴스·이벤트 수집
- **discord-reader**: `get_latest_holding` — #holdings 채널 보유 종목 읽기
- **discord-notifier**: `send_discord_message`, `send_stock_alert` — 매매 신호 전송
- **yfinance**: `get_realtime_price`, `get_stock_info`, `get_intraday_ohlcv`, `get_multi_quote`
- **alphavantage**: `get_rsi`, `get_ohlcv`
- **macd-analyzer**: `get_macd`, `get_macd_multi`
- **financial-datasets**: `get_company_news`

---

## 실행 지침

### STEP 0 — 거시 환경 파악 및 보유 종목 불러오기

**0-A. 거시 뉴스 수집**
아래 순서대로 수집하여 매매 신호의 신뢰도 조정 기준으로 활용하라.

1. **Google 검색 (WebSearch)** — 아래 2개 쿼리를 순서대로 검색하라 (**최근 3일 이내** 뉴스만 참고하라):
   - `"stock market news last 3 days FOMC CPI earnings"` — 단기 변동성 촉발 이벤트
   - `"geopolitical risk trade war sanctions news"` — 갭 리스크 원인
   각 결과에서 **발행일이 3일 이내**인 기사만 참고하고, 향후 3일 이내 예정된 이벤트를 우선 추출하라.
   오래된 뉴스는 무시하라.

2. **시장 지표 스냅샷** — yfinance `get_multi_quote` 호출 (tickers: ["SPY", "QQQ", "IWM", "TLT", "VXX"]):
   - SPY/QQQ/IWM: 대형주·기술주·소형주 방향성 (단기 추세 편향 파악)
   - TLT: 장기 국채 (급등 = 위험 회피 심리)
   - VXX: 변동성 지수 프록시 (VXX +5% 이상 = 공포 구간 → 매수 신호 기준 강화)

3. **뉴스 보완** — financial-datasets `get_company_news` 호출 (ticker="SPY", limit=5):
   - Google 검색에서 놓친 종목별 이슈를 보완하라.
   - 전반적 시장 심리를 "🟢 위험 선호 / 🟡 중립 / 🔴 위험 회피" 로 한 줄 요약하라.

수집 결과를 아래 형식으로 정리하여 분석 시작 전 Discord에 `send_discord_message`로 전송하라:
```
🌐 거시 환경 스냅샷
  SPY: +X.X% | QQQ: +X.X% | IWM: +X.X% | TLT: +X.X% | VXX: +X.X%
  시장 심리: 🟢/🟡/🔴 [한 줄 요약]
  주요 이슈: [뉴스 헤드라인 1~2개]
  이벤트 경고: [없음 / FOMC D-X / CPI D-X / 기타]
```

> 거시 심리가 🔴 위험 회피이거나 VXX +5% 이상일 경우:
> RSI 매수 기준을 30 → 25 이하로 강화하고, R:R을 최소 1:3 이상만 허용하라.

**0-B. 보유 종목 불러오기 및 종목별 뉴스 수집**
discord-reader MCP의 `get_latest_holding`을 호출하여 보유 종목 목록을 파싱하라.
단기 매매 대상은 **미국 주식(USD)** 만 분석하라. KRW 종목은 건너뛴다.

미국 주식 종목이 확정되면 각 종목에 대해 아래 2가지를 수집하라 (**최근 3일 이내** 뉴스만):
1. **WebSearch** — `"[종목명] stock news last 3 days"` 쿼리로 검색하여 주요 헤드라인 1~2개 추출
2. **financial-datasets `get_company_news`** — 해당 티커로 호출 (limit=3), 날짜가 3일 이내인 것만 사용

수집한 종목별 뉴스는 STEP 5(이벤트 위험 확인)와 병합하여 활용하라.
실적 발표·부정 이슈가 이미 발견된 종목은 STEP 5를 별도 호출 없이 이 결과로 대체해도 된다.

### STEP 1 — 추세 필터: 200일 SMA 확인
yfinance MCP의 `get_stock_info`를 호출하여:
- `twoHundredDayAverage` (200일 SMA) 와 현재가를 비교하라.
- **현재가 > 200일 SMA**: 매수 관점 유지 → 다음 단계 진행
- **현재가 ≤ 200일 SMA**: 하락 추세 — "⛔ 추세 필터 미통과" 로 표시하고 해당 종목 분석을 중단하라.
  단, 공매도 관점 종목은 반대 조건(현재가 < 200일 SMA)을 적용하여 분석 가능.

### STEP 2 — 모멘텀 진입 신호: RSI(14)
alphavantage MCP의 `get_rsi`를 호출하여 (interval=daily, time_period=14, limit=5):
- 최근 5일 RSI 흐름을 확인하라.
- **RSI 30 이하 → 30 상향 돌파**: 강한 매수 신호 🟢 — 과매도 탈출
- **RSI 30~50**: 중립 (회복 중) 🟡
- **RSI 50~70**: 추세 유지 (추격 매수 주의) 🟡
- **RSI 70 이상**: 과매수 — 신규 진입 금지 🔴

### STEP 3 — 추세 확인: MACD 신호
macd-analyzer MCP의 `get_macd`를 호출하여:
- **기본 설정 (스윙 트레이딩)**: MACD(12, 26, 9)
- **빠른 설정 (단기/데이 트레이딩)**: MACD(8, 21, 5) — 단, 가짜 신호 위험 증가
- 신호 판단:
  - 골든크로스 (MACD > Signal, Histogram 양전환): 모멘텀 가속 확인 🟢
  - 데드크로스 (MACD < Signal, Histogram 음전환): 진입 보류 🔴
  - Histogram 방향만 확인 시: 상승추세 / 하락추세로 표시

### STEP 4 — 단기 가격 흐름: 인트라데이 OHLCV
yfinance MCP의 `get_intraday_ohlcv`를 호출하여 (interval=60m, period=5d, limit=20):
- 최근 20개 60분봉을 분석하여 스윙 저점(Swing Low)을 확인하라.
- 스윙 저점: 최근 20봉 중 가장 낮은 저가 (Low) → 손절가 기준으로 사용
- 거래량 급증(평균 대비 150% 이상) 여부를 확인하라. MACD 신호와 겹칠 때 신뢰도 상승.

### STEP 5 — 이벤트 위험 확인
financial-datasets MCP의 `get_company_news`로 최신 뉴스 5건을 조회하라.
다음 항목을 확인하여 이벤트 위험을 판단하라:
- 향후 3일 이내 **실적 발표(Earnings)** 예정 → "⚠ 실적 발표 임박" — 포지션 규모 50% 축소 권고
- 주요 경제지표 발표, 금리 결정 등 변동성 이벤트 → "⚠ 거시 이벤트" 경고
- 부정적 뉴스 (소송, 규제, CEO 사임 등) → "🔴 리스크 이벤트" — 진입 금지

### STEP 6 — 매매 계획 수립 (R:R / 포지션 사이징)
아래 공식으로 손절가, 익절가, 포지션 크기를 계산하라.

**손절가 (Stop-loss)**
```
손절가 = STEP 4에서 확인한 스윙 저점 - (ATR 또는 최소 0.5%)
```

**익절가 (Take-profit) — R:R 비율 적용**
```
손절 거리 = 진입가 - 손절가

R:R 1:2 (기본, 스윙 트레이딩):  익절가 = 진입가 + (손절 거리 × 2)
R:R 1:3 (강한 추세 구간):       익절가 = 진입가 + (손절 거리 × 3)
```

R:R 선택 기준:
- RSI 과매도 탈출 + MACD 골든크로스 동시 발생: **1:3 적용**
- 조건 하나만 충족: **1:2 적용**

**포지션 크기 (총자산의 1% 리스크 제한)**
```
포지션 크기(주) = (총 자산 × 1%) / (진입가 - 손절가)
```
> 총 자산이 불명확한 경우 "$10,000 기준"으로 예시 계산하라.

### STEP 7 — 종합 신호 판단 및 Discord 전송
아래 형식으로 **종목별 매매 신호 카드**를 작성한 뒤,
discord-notifier MCP의 `send_stock_alert`로 Discord에 전송하라
(색상: 매수신호=녹색 0x00b050, 관망=노란색 0xffc000, 진입금지=빨간색 0xe74c3c).

```
──────────────────────────────────
⚡ [종목명] ([티커]) — 단기 매매 신호
──────────────────────────────────
현재가:      $XXX.XX
200일 SMA:   $XXX.XX  [추세 위 ✓ / 추세 아래 ✗]

📊 기술적 신호
  RSI(14):   XX.X  [과매도 탈출 🟢 / 중립 🟡 / 과매수 🔴]
  MACD:      [골든크로스 🟢 / 데드크로스 🔴 / 상승추세 / 하락추세]
  거래량:    [급증 ✓ / 보통]

🎯 매매 계획  (R:R 1:X)
  진입가:    $XXX.XX  (현재가 기준)
  손절가:    $XXX.XX  (스윙 저점, -X.X%)
  익절가:    $XXX.XX  (+X.X%)
  포지션:    XX주  ($10,000 기준, 손실 한도 $100)

⚠ 이벤트 위험
  [없음 / 실적 발표 D-X / 거시 이벤트 / 리스크 이벤트]

🚦 최종 신호:  ★ 매수 진입 / 관망 / 진입 금지
──────────────────────────────────
```

**최종 신호 판단 기준**:
- ★ **매수 진입**: 추세 필터 통과 + RSI 과매도 탈출 + MACD 골든크로스 or 상승추세
- ⏸ **관망**: 조건 1~2개 미충족 또는 이벤트 위험
- ⛔ **진입 금지**: 추세 필터 미통과 or RSI 과매수 or MACD 데드크로스 or 리스크 이벤트

전체 종목 분석 후 `send_discord_message`로 **요약**을 전송하라:
- 매수 진입 / 관망 / 진입 금지 종목 수
- 가장 강한 신호 종목 (모든 조건 충족)

---

## 주의 사항
- alphavantage RSI는 무료 플랜 기준 **일봉(daily)** 만 안정적으로 동작한다.
  인트라데이 RSI가 필요하면 yfinance `get_intraday_ohlcv` 데이터를 직접 계산하라.
- alphavantage MACD는 유료 플랜 전용이다. 항상 **macd-analyzer MCP**를 사용하라.
- yfinance `get_intraday_ohlcv` 1분봉은 최근 7일, 60분봉은 최근 60일까지만 조회 가능.
- 포지션 사이징 계산 시 손절가 = 진입가가 되는 경우(손절 거리 0) 해당 종목은 계산 불가로 표시하라.
- 각 종목 분석 시작 시 `send_discord_message`로 "[종목] 단기 분석 중..." 을 전송하라.
